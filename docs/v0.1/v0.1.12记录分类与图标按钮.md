# v0.1.12 记录分类与图标按钮

**状态：已确认**

## 背景与目标

为记事记录加入分类，在状态球输入框中同时支持选择和快捷切换类型。将历史入口移到主窗口工具栏，并用图标呈现各操作按钮。

## 范围与行为

- 在主窗口「颜色时间表」左侧添加「记录分类」按钮，点击后打开分类管理窗口。
- 编辑或删除分类时，发起操作后弹出「是否应用于历史？」，根据用户选择处理使用该分类的已有记录。
- 在状态球弹出的输入框左侧加入类型选择器。新记录默认选择「普通」，保存时一起保存所选类型。
- 在空白正文中输入 `/类型` 并按空格，匹配成功时切换到对应类型，同时清空命令文本，不提交记录。输入一个字也可匹配列表中第一个符合的类型。
- 移除分割线下方的本地日期时间入口，把同一月历入口改为「历史」，放在主窗口「设置」左侧。月历色阶、悬停预览和固定浏览方式继续适用。
- 将主窗口分割线上方的悬浮窗开关、「记录分类」、「颜色时间表」、「历史」和「设置」改为图标按钮。鼠标悬停显示按钮说明，键盘和屏幕阅读器仍能识别其用途。

## 非目标与兼容边界

沿用 Windows、.NET 8 和 WPF。本轮增加分类信息，不改变记录日期分组或计时规则。已有记录缺少类型字段时按「普通」处理。

## 已确认事项

| 问题 | 确认结论 | 理由 |
| --- | --- | --- |
| 分类管理提供哪些操作？ | 「普通」固定在首位，可新增、重命名、上移、下移和删除其他类型。类型名称不能为空、不能重复，不能含空白或斜杠。 | 顺序可控制快捷匹配结果。 |
| 「是否应用于历史？」的选项如何处理？ | 提供「应用于历史」「仅影响以后」「取消」。重命名时，应用于历史会把已有记录的分类名一起改为新名称。删除时，应用于历史会把已有记录归入「普通」。选择仅影响以后时，已有记录保留原分类名称，后续类型选择和快捷匹配使用更新后的分类列表。取消则放弃这次操作。 | 用户可决定是否批量调整历史分类。操作只涉及分类，保留记录正文、日期、颜色和耗时。 |
| 如何判定快捷命令的匹配结果？ | 仅在正文当前完全由一个斜杠命令组成、且光标位于末尾时识别。优先匹配完整名称，其次按分类列表顺序匹配名称前缀。例如有「工作」和「工单」时，输入 `/工` 加空格选中排序靠前的一项。没有匹配时保留原文和空格。 | 避免误删包含斜杠的普通文本，也让简写结果可预期。 |
| 分类在记录列表、编辑和草稿中如何表现？ | 非「普通」记录在主窗口与历史预览中显示简洁的类型标签。编辑已有记录时可修改类型和正文，保留原日期、颜色、耗时及当前计时。1 分钟草稿同时保留正文和已选类型。 | 保存后可辨识分类，修正类别时也能保留原始记录信息。 |

- 图标化仅适用于主窗口分割线上方的五个操作按钮。悬浮窗开、关使用不同图标和提示。

3. 从主窗口和悬浮窗打开输入框，验证类型选择器、完整名称、单字前缀、多个匹配及无匹配时的处理。快捷切换成功只修改类型并清空命令，不保存、不重置计时。
4. 新记录保存所选类型，旧记录默认普通。验证编辑和草稿恢复时的类型行为。
5. 检查主窗口分割线上方的五个图标按钮。悬停提示准确，键盘可操作，悬浮窗开关的两种状态使用对应的图标和提示。

## 技术设计

- 本地记录文件改为带版本号的对象，包含分类顺序及记录。读取时兼容旧版记录数组。分类和历史记录在同一个写锁及文件替换操作中更新。
- 分类具有固定标识，记录保存分类标识和提交时的名称。仅影响以后时，已保存的名称保留。应用于历史时，按分类标识更新已有记录。删除后新增同名类型会创建新标识。
- 新增和编辑共用类型下拉选择器。快捷命令只在正文末尾处理，按完整名称和分类顺序选择。历史记录可以保留旧名称。
- 主窗口使用五个矢量图标按钮，说明同时用于悬停和辅助功能名称。历史入口沿用现有月历窗口。
