# v0.1.13 数据备份与设置整理

**状态：已确认**

## 背景与目标

在设置中提供历史导出、完整备份和恢复。「历史」提供并列的「按日期」和「按分类」入口。「颜色时间表」使用与日历图标更容易区分的图案，现有设置按用途整理。

## 范围与行为

- 在设置中新增「数据导出」「自动备份」和「恢复」。导出包含全部日期的历史记录及每条记录保存的分类名称、日期和时间、颜色与耗时。完整备份覆盖全部应用数据，两种文件用途各自明确。
- 「历史」提供并列的「按日期」和「按分类」。「按日期」沿用现有月历、色阶和悬停预览。「按分类」选择一种分类后，列出该分类跨所有日期的记录，每条显示记录时的日期和时分。
- 更换主窗口「颜色时间表」按钮图标，保留原悬停提示和操作。
- 整理设置窗口。保留现有开关与状态球大小的功能和保存值，让分组、标签和控件更易扫描。

## 非目标与兼容边界

沿用 Windows、.NET 8 和 WPF。数据写入本机和用户指定的导出位置。本轮排除云同步、跨设备合并和自动覆盖恢复。历史按原记录日期分组，原有记录、分类和颜色规则继续可用。

## 已确认事项

| 问题 | 确认结论 | 理由 |
| --- | --- | --- |
| 导出和备份包含哪些数据？ | 导出仅包含历史记录及其元数据。备份包含全部应用数据。两者使用带格式版本号的 JSON。 | 浏览或留存历史时只需记录，恢复应用时需要完整数据。 |
| 如何安排自动备份？ | 默认开启并允许关闭。在应用运行期间，按本地日期最多创建一份自动备份。首次检测到数据有变化时创建，保留最近七份。设置页显示最近成功时间和失败状态。 | 提供多个恢复点，同时限制备份数量。 |
| 恢复时如何处理当前数据？ | 先校验文件并显示备份时间、记录数和分类数，再由用户确认是否替换。恢复前另存当前数据的恢复前副本。校验失败或写入失败时保留当前数据。恢复成功后刷新记录、分类、月历及已恢复的外观配置。 | 覆盖操作的影响清楚，也能在选错文件时找回原数据。 |
| 如何按分类浏览历史？ | 「按分类」和「按日期」为同一级入口。分类视图按记录中保存的分类名称查询，提供「普通」、现有分类和历史保留的名称。比如选择「工作」，可看到所有日期的工作记录，每条都显示日期。月历沿用日期视图的全量统计。 | 用户可以按天翻阅，也可以沿同一分类回看不同日期的活动。 |
| 颜色时间表使用什么图标？ | 使用一条带色点的时间轨道，保留「历史」的日历图标。 | 轨道和色点直接对应颜色规则，在小尺寸下也能与日历轮廓区分。 |
| 设置如何组织？ | 分为「启动」「悬浮窗与状态球」「数据」三组。开机自启、静默启动和启动时打开悬浮窗归入「启动」。全屏隐藏和大小归入「悬浮窗与状态球」。导出、备份和恢复归入「数据」。采用浅色分组、右侧开关和清晰的大小数值。 | 保留熟悉的设置名称，并让启动、显示和数据操作各有固定位置。 |

## 已确认细节

| 问题 | 确认结论 | 理由 |
| --- | --- | --- |
| 历史导出文件能否用于恢复？ | 「恢复」只接受完整备份文件，支持选择自动备份、本地恢复前副本或手动保存的完整备份。数据区增加「立即备份」，可将完整备份保存到指定位置。 | 历史导出缺少应用配置。独立的完整备份入口可以在换机前主动保存可恢复的数据。 |
| 完整备份与恢复是否包含设备相关设置和临时状态？ | 完整备份纳入所有已保存设置，包括开机自启、启动偏好、悬浮窗位置和自动备份开关。恢复提供「仅恢复历史数据」「仅恢复设置」「恢复全部」。历史数据包含记录和分类。恢复设置时用当前安装路径处理开机自启，悬浮位置失效时调整到可用屏幕内。当前计时、未提交草稿及已有备份文件排除在备份之外。 | 用户可以独立恢复历史或设置。临时状态及备份副本各自独立。 |

## 验收条件

1. 可将全部历史记录导出到指定位置。重新打开文件校验记录数、日期与时间、历史分类、色值和耗时。完整备份另行校验确认纳入的全部配置。
2. 自动备份的开关、日期频率、保留份数和最近备份状态符合确认结论。关闭后不新增自动备份。
3. 从完整备份分别验证仅恢复历史数据、仅恢复设置和恢复全部。校验失败、取消、写入失败和成功恢复均有对应反馈。成功恢复前保留一份当前数据副本。
4. 「按日期」保留现有月历色阶和预览。「按分类」选择「工作」后，显示跨月的全部工作记录，每条保留原日期和时分。验证「普通」及已删除分类保留的历史名称也可浏览。
5. 「颜色时间表」图标与「历史」可清楚区分，按钮功能和悬停说明保持可用。重新分组后，现有设置能正常操作，原有值保留。

## 技术设计

- 历史导出和完整备份使用不同文件标识。备份包含现有记录对象和已保存设置的快照，沿用现有记录格式和 Windows 设置存储。
- 恢复前校验备份并生成完整恢复前副本。持有记录写锁期间更新选定数据。设置写入或随后记录替换失败时回滚已写设置，正式记录通过同目录文件替换提交。
- 自动备份按本地日期命名，比对最近自动备份内容，仅在持久化数据有变化时创建。定期保留最近七份自动备份，恢复前副本单独列出。
- 历史窗口的日期视图与分类视图并列。分类视图复用记录行并显示原始本地日期。
