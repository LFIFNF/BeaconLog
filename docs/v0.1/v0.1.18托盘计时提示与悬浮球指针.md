# v0.1.18 托盘计时提示与悬浮球指针

**状态：已确认**

## 背景与目标

用户悬停托盘图标时可以查看当前经过时间。鼠标移到悬浮状态球时继续使用系统默认指针。

## 范围与行为

- 鼠标悬停在 Windows 托盘的 BeaconLog 图标上时，提示显示软件名及「已经过 X 分钟」。
- 鼠标移到悬浮状态球上时保持默认指针。单击打开记录输入框、按住拖动、右键打开菜单等鼠标操作继续可用。

## 非目标与兼容边界

沿用 Windows、.NET 8 和 WPF。托盘提示复用现有计时，不改变计时、重置、记录数据或悬浮窗行为。

## 已确认事项

| 问题 | 确认结论 | 理由 |
| --- | --- | --- |
| 托盘提示如何显示和更新？ | 首行显示「BeaconLog」，次行显示「已经过 X 分钟」。使用与主窗口相同的整分钟口径。在跨分钟或重置时刷新，主窗口隐藏和静默启动时也正常更新。 | 两处读数一致，在托盘运行时也能查看当前计时。 |

## 验收条件

1. 悬停托盘图标时可看到软件名和整分钟计时。跨分钟及重置后再次悬停，显示最新值。
2. 主窗口隐藏或静默启动时，托盘提示仍显示并更新计时。
3. 悬停悬浮球时使用默认指针。分别验证单击、拖动和右键菜单仍可用。

## 实施与验收

托盘和主窗口使用相同的整分钟值和文案，按分钟变化刷新。移除了悬浮球专用的移动指针，保留原鼠标事件绑定。
