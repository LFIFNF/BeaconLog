# v0.1.5 悬浮窗涟漪与状态球背景

**状态：已确认**

## 背景与目标

悬浮窗目前只显示状态球。打开时增加一道短暂的色带涟漪，帮助用户定位状态球。为悬浮窗添加球体背后的圆形背景层，使其随状态球大小和颜色变化，并允许用户单独设置背景层透明度。

## 范围与行为

- 打开悬浮窗时，以状态球为中心显示一道向外扩散并淡出的环形色带。涟漪结束后只保留状态球和背景层。
- 背景层与状态球同心，调整状态球大小时同步缩放，改变状态球颜色时实时更新为对应的浅色。
- 在「调整状态球」窗口增加「背景层透明度」滑块。改动即时预览并保存。透明度仅作用于背景层，状态球保持原色，定位涟漪仍可见。

## 非目标与兼容边界

沿用 Windows、.NET 8 和 WPF。保留已有状态球大小、颜色和启动设置，旧版缺少背景层透明度时使用默认值。悬浮窗继续支持拖动和右键关闭，返回托盘时继续显示。本轮范围限于视觉提示和外观设置。

## 已确认事项

| 问题 | 确认结论 | 理由 |
| --- | --- | --- |
| 哪些打开方式播放涟漪？ | 手动打开、启动时自动打开，以及悬浮窗已存在时再次点击「打开悬浮窗」，都在当前位置播放一次。连续点击时从头重播同一道涟漪。调整大小、颜色或透明度时保持当前显示，不触发涟漪。 | 用户再次点击入口时也能定位已有的悬浮窗。 |
| 涟漪采用什么颜色和时长？ | 使用当前状态球颜色，从背景层外缘扩散并在约 600 毫秒内淡出。遵循 Windows 动画设置，关闭系统动画时用短暂的静态色环提示。提示层不拦截鼠标操作。 | 保持反馈短暂，并兼顾关闭系统动画的用户。 |
| 背景层如何跟随大小和颜色？ | 背景圆直径为状态球直径的 1.5 倍，颜色采用当前球色与白色混合，白色占 65%。 | 保留球色的色相特征，且在各档尺寸下留出稳定的背景边缘。 |
| 透明度用什么范围，在哪里预览？ | 滑块显示 0%–100% 的透明度，默认 30%。0% 表示背景层完全不透明，100% 表示完全透明。主窗口预览和悬浮窗实时同步，重启后保留。 | 用户可以从主窗口直接查看背景效果，也可以完全隐藏背景层。 |

## 验收条件

1. 按已确认的触发方式打开或唤回悬浮窗时，能看到以状态球为中心的定位提示。提示结束后消失，拖动和右键关闭仍可操作。
2. 在最小和最大球径之间拖动大小滑块时，背景层同步缩放且保持同心。更换球色后，背景层更新为对应的浅色。
3. 调节透明度时，两处预览即时同步。在 0% 和 100% 两端分别检查背景层完全不透明和完全透明，球体及定位提示不受影响。
4. 重启后保留已设置的背景透明度。旧版升级时沿用已有外观与启动设置，并使用确认的默认透明度。
5. 验证关闭 Windows 动画时的提示形式，以及悬浮窗靠近工作区边缘时仍能看到定位提示。

## 技术设计

- 在现有外观设置中保存背景层透明度。主窗口和悬浮窗从同一外观对象获得背景层直径、浅色和不透明度。
- 涟漪使用独立的透明提示窗口，以悬浮窗为所有者并跟随其中心。提示窗口不接收鼠标输入，也不抢占焦点。重复定位时重播同一提示，结束后关闭提示窗口。

## 实施与验收

背景层和定位提示按设计实现。主窗口最小宽度由 380 DIP 调整为 400 DIP，为最大背景圆和顶部按钮留出空间。新悬浮窗的默认落点向工作区内留出涟漪空间。
