# v0.1.9 应用图标与状态球交互

**状态：已确认**

## 背景与目标

为 BeaconLog 设计正式应用图标。改进状态球附近的测试输入框、颜色规则的命名和悬浮状态球的位置恢复。

## 范围与行为

- 设计 BeaconLog 专用图标，替换 Windows 系统默认应用图标。
- 状态球弹出的测试输入框可以拖动。输入框获得焦点时，按回车与点击「提交」执行相同操作：清空内容并关闭。两种方式均为测试交互，不创建记录，也不重置计时。Esc 和点击外部仍可关闭。
- 在颜色时间表的新增和编辑表单中加入「颜色标题」文本框，并在列表中显示标题。固定首行的标题与颜色均可编辑，首行仍置顶，其 0 分钟和「到时切换」继续只读。
- 拖动悬浮状态球后保存位置。关闭悬浮窗再打开时，恢复到保存位置。

## 非目标与兼容边界

沿用 Windows、.NET 8 和 WPF。原有颜色、时长、排序、提醒和启动设置继续有效。位置记录仅针对悬浮状态球。测试输入框与主窗口的位置各自独立。未保存过悬浮位置的安装继续使用现有默认落点。

## 已确认事项

| 问题 | 确认结论 | 理由 |
| --- | --- | --- |
| 图标采用什么设计，应用到哪里？ | 以深蓝底、青色状态球和一圈不闭合的定位涟漪为设计方向，使用无文字的轮廓。提供多尺寸 Windows ICO，同步用于可执行文件、窗口和托盘。 | 图形呼应状态球与定位提示，在小尺寸下仍易识别。 |
| 输入框从哪里拖动，是否记住位置？ | 给输入框增加可拖动的顶部区域。拖动只移动本次输入框，文字区域仍可选中文本。下次打开仍从被点击的状态球附近出现。 | 避免拖动与输入冲突，也保持每次打开时的位置可预期。 |
| 标题为空或旧规则没有标题时如何显示？ | 去除首尾空白，允许留空，最多 40 字。首行留空或旧版首行显示「初始颜色」。普通规则留空或旧规则无标题时显示其十六进制色值。允许重复标题。 | 旧规则无需手动补全，新规则也可以只填写颜色。 |
| 位置保存多久，屏幕布局变动时怎么办？ | 拖动结束时保存到当前用户设置，关闭重开及应用重启后均恢复。原显示器不可用或保存位置超出工作区时，调整到可用屏幕的可见范围。 | 避免断开外接屏幕后找不到状态球。 |

## 验收条件

1. 可执行文件、窗口和 Windows 托盘使用正式图标。小尺寸托盘图标可辨认。
2. 在主窗口和悬浮状态球处打开输入框，拖动后仍可输入、选择文字和提交。回车或点击「提交」均清空并关闭，颜色时间表的走时继续。
3. 可在新增和编辑规则时填写标题，列表立即显示保存结果。首行标题可以更改，时间和切换方式仍为只读。旧规则按确认的默认显示规则加载。
4. 拖动悬浮球后，分别通过主窗口按钮和右键菜单关闭再打开，球体出现在原位置。重启后按确认的持久化规则恢复。验证断开显示器或变更屏幕布局后球体仍可见。

## 技术设计

- 将多尺寸 ICO 嵌入可执行文件，并作为 WPF 窗口及托盘共用图标资源。
- 测试输入使用无边框的拥有者窗口，以便通过顶部区域拖动。失去焦点或状态球隐藏时关闭。回车和按钮共用清空并关闭的逻辑。
- 普通规则的 JSON 增加可选标题字段。初始色和标题作为同一个用户设置保存，读取时兼容旧版的单独初始色。
- 悬浮球在拖动完成后保存屏幕坐标。恢复前根据当前位置选择显示器，再将窗口限制在其工作区内。

## 实施与验收

正式图标使用深蓝底、青色状态球和带开口的涟漪，包含 16–256 像素的十种尺寸。颜色时间表最小宽度调整为 440 DIP，为标题列留出空间。输入窗和悬浮窗位置按设计独立处理。
