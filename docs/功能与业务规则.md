# 功能与业务规则

## 主窗口与设置窗口

- 主窗口采用白色主题。顶部显示状态球、悬浮状态、已过分钟数，以及悬浮窗开关、「重置计时」、「记录分类」、「颜色时间表」、「历史」和「设置」图标按钮。悬停可查看说明。分割线下按新增顺序显示今天的记录，加载和新增后滚动到最新一条。
- 「设置」可调整状态球直径（12–48 DIP）。有效改动立即保存，并同步到主窗口和已打开的悬浮窗。
- 「颜色时间表」首行是初始颜色，可修改标题和色值。普通规则可添加、编辑、删除和排序。标题可留空，最多 40 个字符。空标题首行显示「初始颜色」，普通规则显示十六进制色值。每段时长为 10–99 分钟，按列表顺序累计。渐变开启时在该段内逐步变色，关闭时在段末切换。
- 软件启动后按系统时钟计算经过时间。新增记录保存成功后从初始色重新计时。主窗口显示整分钟，主窗口预览和悬浮窗同步变色。应用在托盘中也继续计时，退出后重新启动从 0 分钟起算。
- 主窗口短按或用键盘激活「重置计时」时，在按钮附近显示确认面板。选择悬浮窗右键菜单中的同名操作时，面板出现在状态球旁。默认聚焦「取消」，Esc 或点击外部也会关闭。主窗口按住按钮显示进度，满 0.5 秒直接重置一次。重置后恢复初始色，并清除旧段待补播提醒。
- Windows 实际休眠超过 60 分钟后恢复时，自动重置一次。确认的规则同样适用于应用在托盘中运行。
- 每段可开启涟漪提醒，按 1–99 分钟的间隔播放，默认关闭且间隔为 10 分钟。悬浮窗全屏隐藏期间错过提醒时，退出全屏仍处于原时段则补一次。
- 点击主窗口或悬浮窗的状态球可打开记录输入框，顶部可拖动，左侧类型默认「普通」。当正文仅为 `/名称` 且光标位于末尾时，按空格优先匹配完整名称，否则按分类顺序匹配前缀。匹配成功清空命令，继续输入正文。按回车或点击「提交」保存非空记录。Esc 或点击外部关闭时，未提交文本和所选类型在当前进程内保留 1 分钟。

## 本地记录

- 记录行依次显示当时的状态球颜色、时分、分类和正文。普通记录显示「普通」。时间、分类和正文使用同一文字样式和固定列起点，长正文在正文列中换行。长分类名可悬停查看，悬停时间可查看整分钟耗时。保存时保留带时区偏移的本地日期和时间。
- 双击记录或选中后按回车可修改正文和类型。修改保留原时间、颜色和耗时，当前计时继续。主窗口、日期预览和分类历史共用记录行排版。
- 右键主窗口记录可编辑或删除被点击的条目。删除前显示正文摘要并要求确认。保存成功后同步刷新主窗口和历史，当前计时继续。
- 「记录分类」支持添加、排序、重命名和删除。「普通」固定首位。重命名或删除时可选择应用于历史、仅影响以后或取消。删除并应用于历史时，相关记录归入「普通」。
- 点击「历史」图标可选择「按日期」或「按分类」。日期视图沿用月历，每月以单日最高记录数为 100%。悬停或用键盘聚焦日期可预览当天记录，点击或按回车可固定预览。分类视图显示所选分类跨日期的记录，每条带原日期和时分。两种视图均可选中记录按 Ctrl+C 复制，或按回车进入编辑。
- 主窗口跨午夜后显示新一天的记录。日历按记录保存时的本地日期分组，保持当前浏览的月份和预览日期。日历中的「回到今天」可直接返回当月。
- 记录保存在当前用户的 `%LOCALAPPDATA%\BeaconLog\records.json`。提交失败时输入框保留原文和错误提示，计时继续。

## 导出、备份与恢复

- 「设置」按「启动」「悬浮窗与状态球」「数据」分组。「导出历史」生成只包含记录的 JSON。「立即备份」生成包含记录、分类及全部已保存设置的完整备份。
- 自动备份默认开启。当持久化数据有变化时，每个本地日期最多创建一份，最多保留最近七份。应用在运行时检查备份状态。
- 恢复仅接受完整备份文件。确认后可仅恢复历史数据、仅恢复设置或恢复全部。恢复前另存当前数据副本。当前计时和草稿属于临时状态，不进入备份。
- 恢复设定途中退出时，下次启动会根据恢复前副本回滚未完成的操作。
- 状态球背景圆直径为球体的 1.5 倍，颜色由球色混入 65% 白色得到。主窗口预览和悬浮窗的背景透明度均固定为 50%。
- 「打开悬浮窗」打开独立的置顶状态球。主窗口按钮随之变为「关闭悬浮窗」。拖动结束后保存位置，关闭重开或重启后会恢复。屏幕布局变化时，悬浮窗会调整到可用屏幕工作区内。也可从右键菜单关闭。预览右侧显示「未开启悬浮窗」「正在悬浮中」或「全屏隐藏中」。
- 手动或启动时自动打开悬浮窗并立即显示时，会播放约 600 毫秒的环形定位涟漪。关闭 Windows 动画时显示短暂的静态色环。全屏退出后自动恢复时不播放提示。
- 点击「设置」打开独立的白色窗口，主窗口仍可操作。同时只打开一个设置窗口。再次点击会激活已有窗口，最小化时先恢复。关闭后可以重新打开。
- 「开机自启」控制当前用户登录 Windows 后是否自动启动 BeaconLog。「静默启动」仅在开机自启时生效，手动启动始终显示主窗口。两项默认关闭，切换后立即保存。即使开机自启关闭，也可预先保存静默启动偏好。
- 「软件启动时打开悬浮窗」默认关闭，切换后立即保存，下次正常或静默启动时生效。
- 「全屏时隐藏」默认开启，切换后立即生效并保存。状态球所在屏幕进入全屏时悬浮窗暂时隐藏，退出全屏后恢复到原位置。临时隐藏时仍可通过主窗口按钮彻底关闭。

## Windows 托盘

- 可执行文件、常规窗口及托盘采用 BeaconLog 正式图标。应用启动即显示托盘图标，图标在主窗口显示、最小化或隐藏期间均保留。Windows 可能将图标放入通知区域的折叠菜单。
- 点击主窗口的关闭按钮会关闭设置和颜色时间表、隐藏主窗口并让应用继续运行。已打开的悬浮窗继续显示。双击托盘图标、在右键菜单选择「打开主窗口」或再次手动启动即可恢复。再次手动启动沿用当前会话中的已有实例。
- 托盘右键菜单中的「退出」会关闭应用及其所有窗口，并移除托盘图标。
