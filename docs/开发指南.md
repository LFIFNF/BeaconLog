# 开发指南

## 本地记录文件

当前用户的记录保存在 `%LOCALAPPDATA%\BeaconLog\records.json`。v0.1.12 读取旧版记录数组或版本化对象。首次成功写入后保存为含 `Version`、`Categories` 和 `Entries` 的对象，当前版本号为 `1`。上一版程序只读取数组格式。

修改记录及分类请通过 `JournalStore`。写入期间持有相邻的独占锁文件，读取最新内容，写入并刷新临时文件，再替换正式文件。字段含义及历史应用规则见 v0.1.12 需求和系统架构与设计。

## 备份文件

自动备份和恢复前副本位于 `%LOCALAPPDATA%\BeaconLog\Backups`。自动备份名为 `automatic-YYYY-MM-DD.json`，恢复前副本以 `before-restore-` 开头。自动清理只处理自动备份。

历史导出标识为 `BeaconLog.History`，完整备份标识为 `BeaconLog.Backup`，两者格式版本均为 `1`。恢复操作通过 `BackupService` 校验备份、保存副本后执行。
